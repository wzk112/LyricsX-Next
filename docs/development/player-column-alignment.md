# 主窗口封面与播放条对齐

状态：2026-10-02 本地修复，未纳入公开版本。

## 问题和修改

- 主窗口高度受限时，封面会按剩余高度缩小，但歌曲信息和播放进度仍使用完整列宽，导致右边缘不齐。
- 封面、歌曲信息和进度条使用同一个有效宽度，并在原有播放器栏内居中。播放器栏和歌词区域的分界位置保持不变。
- 播放按钮的固有宽度不再反向撑大进度条；短窗口中按钮维持原有大小，并与封面共用中心线。
- 暂停时不再把封面缩小到 94%，改为平滑改变阴影深度，保持封面边缘与播放条一致。
- 紧凑布局仍使用 64 pt 封面，原有歌词视口、封面交接及进度拖动逻辑保留。

## 验证

原生 macOS 窗口使用实际封面组件、歌曲信息与播放进度控件。红色测试封面仅用于识别真实渲染边缘，不是用户音乐的实机截图。

覆盖 1100×740、1100×440、790×640、790×430 的播放和暂停状态，以及回到较大窗口、跨入紧凑布局和长标题／艺人／专辑名。封面与进度控件的两边相差不超过 0.5 pt，播放与暂停状态不改变封面边界，歌词滚动视口未替换。
