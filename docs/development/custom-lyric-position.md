# 主窗口歌词自定义位置

状态：已纳入 2.0.40（275）。功能、安装和验证说明见 `docs/releases/v2.0.40.md`。

## 功能

- 入口：设置 → 歌词 → 文字 → 主窗口当前歌词位置 → 自定义。
- 可拖动滑块或输入 5%–95% 的整数；从歌词区域顶部计算，数值越小越靠上。
- 居中（50%）与上方（30%）保留原行为。切回预设不删除自定义数值；旧用户的原有位置设置保持不变。
- 同一句的百分比变化会重新定位；手动浏览时保留浏览状态，返回当前歌词仍使用已有滚动过渡。
- 首尾滚动留白、当前行锚点和上下边缘淡出共同使用解析后的有效位置，避免靠近边缘时当前句被固定淡出区遮住。
- 新手教程已说明自定义选项；应用内位置演示同步实际百分比。悬浮窗布局独立。

## 验证

- 完整 Swift 测试：431 项通过（Services 104、Core 42、App 285）。
- 自定义设置的保存、预设切换、旧设置兼容、越界及非有限数值、长于视口的歌词和返回动画策略均有测试。
- 真实 macOS 开发构建：逐键输入 1 再 2 得到 12%，5% 与 95% 正常；输入 99 后回车及失焦显示和保存为 95%。验证后恢复原来的上方预设和正式安装包。
- 原生窗口回归覆盖前奏、首句、中间长句、末句、翻译切换及尺寸变化；同时检查远距离跳句的实际滚动方向与幅度，防止旧行停在锚点产生假通过。
- 本项未修改 Flexbar 或音频采集。没有发布或替换 GitHub 的 2.0.39 下载资产。
