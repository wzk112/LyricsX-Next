# LyricsX Next 2.0.34

本次更新相对于 GitHub 上一个正式版本 **v2.0.28**，汇总尚未发布的本地改动。发布前待确认。

## 新增
- **自定义字体与颜色**：选择本机字体，分别调整原文和辅助文字；支持逐字歌词已唱、未唱的独立配色，并提供实时预览。
- **封面主题色**：歌词可选跟随封面颜色，通过同色系明暗区分逐字进度；无封面时使用中性颜色，关闭后恢复手动配色。主界面背景保留更多封面色彩，减少偏灰黑的观感。
- **首次使用教程与更新介绍**：全新安装展示 10 页图文教程，涵盖播放器连接、主界面、搜索、悬浮窗、材质、字体、辉光、同步和本地歌词管理。可在教程中直接调整悬浮窗、鼠标穿透、辅助文字、来源排序及逐字／双语优先。
- 已有安装只显示更新摘要，每个版本仅自动展示一次；可在 **设置 → 关于** 重看完整教程或本次更新。

## 修复
- 修复屏幕参数通知在展开／收回过程中取消尺寸动画、使悬浮窗停在中间高度的问题；无需鼠标经过才能恢复。
- 修复屏幕参数通知从后台线程到达时，EDR 检测回调违反主线程隔离而可能触发崩溃的问题。
- 修复 QQ 两个搜索接口返回顺序变化时空结果重试可能失效的问题，保留并行检索。
- 修复启动后必须先打开主窗口才出现悬浮窗，以及菜单栏歌词不显示的问题。
- 统一透明悬浮窗的可见性与显示链接判断，避免系统遮挡通知错误暂停逐字动画。
- 统一文字测量与原生窗口的尺寸取整，避免同一句播放过程中重复触发无效缩放。
- 改进歌词替换、等待状态进入歌词和窗口生命周期变化时的重新测量，减少高度未更新、文字越界与残留布局问题。
- 修复切换自定义字体后的字号缩小和对齐偏移；保留用户设定字号，统一原文、下一句和离场文字的对齐，并测量备用字形的真实行高。
- 修复简繁体转换后逐字高亮与长音辉光失效；转换只影响显示，保留匹配的逐字时间，不改写歌词文件。
- 改进封面、歌曲信息和背景切歌过渡；短暂缺图时保留上一帧，背景完成处理后平滑切换，减少闪烁。
- 补充窗口显示后的 EDR 状态刷新；逐字自定义配色仍支持增强辉光，最终亮度受屏幕与系统可用余量限制。
- 修复极端歌词偏移值在调整或重置时可能导致的溢出。
- 校验旧设置中的无效字号、宽度和辉光亮度；登录启动状态与系统同步，并提供待批准入口和错误提示。

## 性能与设置
- 封面解码与像素解压移至后台串行处理，复用最近一张相同封面，取消过期切歌任务；避免切歌时同步封面处理阻塞主窗口与悬浮窗动画。
- 逐字、辉光与滚动文字使用连续的字形位置绘制，减少微小缩放与移动的跳格感；静止与运动时使用相同绘制策略，避免高亮开始或结束时跳变。
- 对播放器的小幅时间回报抖动做显示层平滑校正，减少逐字和辉光跳动；歌词时间、切歌、暂停与拖动进度仍即时响应。
- 重写设置页导航、边栏开合和卡片样式，统一 SF Symbols 尺寸、字重与对齐；展开／收起保持右侧阅读列宽度，避免动画期间反复换行和重排预览。
- 长音强调改为词内字符依次起伏，平滑放大与回落的起止速度；保留真实逐字时间、连字排版和 EDR 增强，辉光共用绘制层。设置预览同步展示缩放，可见时以 60 帧播放；修复开始高亮和临近唱完时遮罩边缘突亮、突暗。
- 优化 QQ 歌词 XML 清理：正常长文本一次向前遍历，避免逐字符从头计数和定位，降低搜索时的 CPU 峰值。
- 播放器发现列表随应用启动、退出和唤醒更新，避免每秒重新筛选所有运行应用；自动检测与浏览器排除规则保留。
- 合并歌词缓存的文件读取与解码，缓存字体行高、字体名称和简繁转换结果，清理已失效的文件路径。
- 封面取色使用小尺寸 CPU 采样；背景颜色增强烘焙进原有缓存图，不添加实时全窗口模糊层。
- 隐藏的预览停止刷新，关闭介绍窗口释放预览；清理迟到的窗口回调与通知监听。
- 修复悬浮窗托管视图与应用模型的循环引用，计时器释放后停止刷新；停止的播放器与搜索不被迟到通知重新启动。
- 关闭资料库时释放文档并取消扫描；为路径缓存和子进程错误输出设置内存上限，避免长期积累。
- 设置说明使用完整行宽，相关控件按辅助文字模式显示；明确系统减少动态效果、降低透明度等限制。

原有动画效果与默认帧率策略保留，未通过统一降低帧率来掩盖性能问题。

## 使用说明
介绍页根据同一 macOS 用户的应用偏好判断首次使用与更新；清空偏好或使用新账户会视为首次安装。旧版本没有介绍记录时，展示本次合并摘要。

搜索仍依赖各来源可用性。自定义字体的缺失字形由系统回退；复杂桌面背景可选择磨砂阅读提高对比度。
