# LyricsX Next 2.0.34

**自定义字体、自由配色，让歌词跟随歌曲封面。**

本次更新汇总了上一公开版本 **2.0.28** 之后的全部变化。正式安装包为 **2.0.34（258）**。

## 个性化歌词

- **自定义字体与字号**：可选择本机字体，分别调整原文、翻译和下一句；缺少字符时自动使用系统字体，主窗口与悬浮窗保持相同排版。
- **完整文字配色**：原文、翻译、下一句，以及逐字歌词“已经唱到”和“还未唱到”的部分均可单独设置颜色。
- **跟随封面主题色**：歌词可以自动使用封面颜色；主界面背景取色也更鲜明，无封面时会回到清晰的中性色。
- **实时预览与恢复默认**：字体、字号、颜色和逐字效果都能直接预览，并可一键恢复默认外观。

## 搜索与播放

- **先预览，再应用歌词**：搜索结果可按当前播放进度预览时间轴、翻译和逐字效果；确认后再应用，搜索列表不会自动关闭，方便继续比较。
- **更可靠的手动选择**：手动应用、导入或从资料库选择的歌词不会再被旧搜索结果覆盖；被停用专辑中的单曲也可单独恢复。
- **自动识别音乐来源**：优先识别 Apple Music、Spotify 等桌面音乐应用，同时避开浏览器和无关媒体来源。
- **播放状态更稳定**：改善快速切歌、暂停、跳转、临时读取失败和播放器元数据分批到达时的衔接，减少封面消失、进度回跳和旧歌词串入新歌。

## 悬浮窗与动效

- **悬浮窗开机即用**：应用启动后直接连接播放器并显示悬浮歌词，不再需要先打开主窗口；菜单栏歌词也能独立保持更新。
- **尺寸立即适配**：等待、单双行歌词、翻译、换字体和手动换歌词都会马上更新高度，并保持顶部位置；拖动过程中缩放不再把窗口拉回。
- **更连贯的换句动画**：下一句从原位置平滑上移，上一句向上模糊淡出；快速歌词、增量文字和无逐字时间的外语歌词也能及时开始并正确结束动画。
- **更稳定的切歌过渡**：标题、封面、背景和歌词只播放一次平滑模糊切换，修复重复闪烁、残留模糊和动画中途卡住的问题。
- **无歌词卡片更自然**：纯音乐或找不到歌词时居中显示封面、歌名和歌手，不再先闪出顶部标题再跳到中间。
- **逐字与辉光优化**：保留逐字提亮、轻微放大、长音辉光和 EDR 增强，改善高刷新率屏幕上的流畅度；自定义颜色仍可使用辉光效果。

## 界面、兼容性与性能

- **重新整理设置**：相关选项会随功能开关显示，文件管理、来源令牌和性能选项集中到开发者选项；“关于”页提供项目、下载、反馈、许可证和上游项目入口。
- **新增图文教程与版本介绍**：首次安装显示完整使用教程，升级用户只看本次变化；启动就绪后会自动置于最前，之后可在“设置 → 关于”重新打开。
- **预览与设置互不干扰**：动效预览在设置窗口内独立显示；关闭预览或版本介绍不会再连带关闭设置窗口。
- **修复字体与转换问题**：自定义字体不再改变实际字号或导致文字偏上，原文与翻译会自动保持间距和对齐；简繁转换继续保留逐字时间。
- **降低后台开销**：减少重复文件读取、字体测量、封面解码和屏幕外绘制，并及时释放关闭的预览、窗口与计时任务，保持现有效果。
- **其他修复**：改善 QQ 音乐歌词读取、缓存文件变化、菜单栏歌词、EDR 屏幕识别，以及关闭或最小化主窗口时悬浮歌词短暂卡顿的问题。

## 下载与安装

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.34.zip`，解压后将 `LyricsX Next.app` 放入“应用程序”。升级会保留已有设置和歌词。

此安装包尚未经过 Apple 公证。如首次打开被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
