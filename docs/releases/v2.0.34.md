# LyricsX Next 2.0.34

## 新功能
- 首次使用展示 10 页图文教程，覆盖播放器、主窗口、搜索、悬浮窗、两种材质、文字、动效、同步、资料库及高级选项。
- 已有安装展示更新内容；版本跳跃合并中间版本说明，每个版本只自动展示一次。设置 → 关于可重看完整教程与本次更新。
- 歌词颜色可跟随封面主题色：已唱明亮、未唱较暗、辅助文字使用浅色；开关默认关闭，保留手动颜色。

## 修复与优化
- 修复简繁转换后逐字高亮和长音辉光消失；验证系统简繁转换后以字素边界映射时间，任意改写文本仍不继承不匹配的时间。
- 主背景增加封面色彩保留度，为偏暗封面补充少量主题底色，保留封面和背景切换过渡。
- 封面取色使用 32×32 CPU 采样并复用结果；背景增强烘焙进原有最长边 384 像素的缓存图，不增加实时模糊层。
- 字体显示名称与简繁转换结果缓存；介绍页只在窗口及页面可见时刷新，关闭后释放预览。
- 字号、宽度和辉光亮度在读入时校验范围；未知中文显示选项回退原文。
- 设置行将说明放在标题与控件下方，避免窄窗口中说明被挤压。辅助字号按模式显示，系统减少动态效果／透明度提供明确状态提示。
- 登录启动串行提交变更并刷新系统状态，显示待批准入口和设置窗口内的错误；关于页面改为 LyricsX-Next 地址。

## 自动介绍识别
以同一 macOS 用户的应用偏好记录识别，检测发生在默认设置迁移前。替换安装包、移动应用或手动下载不会绕过识别；未记录介绍的旧版本根据已有偏好识别为更新，展示近期更新摘要。清空应用偏好或更换全新用户后视为首次使用。未来发布需追加内置版本说明。
