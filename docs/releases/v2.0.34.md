# LyricsX Next 2.0.34

**字体、颜色，自由搭配；歌词随歌曲封面换色。**

## 本次亮点
- **自定义字体**：选择本机字体，分别调整主窗口、悬浮窗和辅助文字的字号，边调边预览。
- **自定义颜色**：原文、翻译可分别选色，逐字歌词也能单独设置已唱和未唱的颜色。
- **跟随封面配色**：开启后，歌词自动搭配当前歌曲封面；主窗口背景也保留更多封面色彩。

以上功能都在 **设置 → 歌词**。

## 更顺畅、更稳定
- 改善逐字高亮、长音辉光和切歌过渡，减少卡顿与闪动，降低不必要的资源占用。
- 修复悬浮窗高度更新不及时、文字被截断，以及启动后需要打开主窗口才显示的问题。
- 修复菜单栏歌词不显示、更换字体后对齐不准、简繁转换后逐字效果失效等问题。
- 改善歌词搜索、封面显示和部分屏幕上的辉光表现。

## 更容易上手
- 搜索支持先预览、再应用，列表保持打开，方便比较不同版本；修复应用歌词后立即消失的问题。
- 重新整理设置页面，改善边栏开合和预览体验。
- 新增图文教程：首次使用介绍完整功能，更新后只展示本次变化，之后不再重复弹出。
- 随时前往 **设置 → 关于** 重看教程或更新介绍。

## 下载与安装
适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.34.zip`，解压后将 `LyricsX Next.app` 放入“应用程序”；升级前先退出旧版，已有设置与歌词会保留。

此安装包尚未经过 Apple 公证。如首次打开被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
