# LyricsX Next 2.0.34

**自定义字体、自由配色，让歌词跟随歌曲封面。**

本次更新汇总了上一个公开版本 **2.0.28** 之后的新增功能与改进。安装包为 **2.0.34（252）**，已补全图文介绍；看过此前简版介绍的用户，会再收到一次完整更新介绍。

## 新增功能

- **自定义字体**：在“设置 → 歌词”选择本机字体，主窗口与悬浮窗一起更换。原文、翻译和下一句可分别调整字号；缺少字符时使用系统字体。
- **自定义文字颜色**：原文、翻译与下一句可以分组配色，两个窗口同步生效并自动保存。
- **逐字独立配色**：已唱到与未唱到分别选色，保留逐字提亮、轻微放大与长音辉光。需要带逐字时间的歌词；关闭后恢复明暗高亮，并保留已选颜色。
- **跟随封面主题色**：自动提取封面颜色，用明暗区分已唱与未唱。无封面时使用中性色，关闭后恢复原来的手动配色。
- **实时外观预览与一键恢复**：设置字体、字号或颜色时直接查看实际歌词排版；“恢复字体与颜色”可回到默认外观。
- **搜索先预览、再应用**：点“预览”，右侧按播放进度显示歌词、逐字效果和翻译，不改正式歌词、不保存。选好后点“应用当前歌词”；列表保持打开，方便继续比较，点“完成”才关闭。
- **完整图文教程与更新介绍**：首次安装介绍播放器、搜索、悬浮窗、材质、字体颜色、动效、同步和文件管理，也可直接调整常用设置。已有用户只看新增内容；之后可在“设置 → 关于”重看，两种介绍都不会每次启动重复弹出。

字体与配色都在 **设置 → 歌词**；歌词搜索使用放大镜按钮或 **⌘F**。

## 界面与体验改进

- **背景取色更鲜明**：主窗口保留更多封面色彩，减少灰黑感；封面背景与歌词跟色可分别使用。
- **重新整理设置界面**：统一侧栏图标与排布，改善边栏开合；相关选项随开关状态显示。文件管理、来源令牌和性能选项集中在开发者选项，日常选项更容易找到。
- **逐字、辉光与切歌更顺畅**：改善文字放大缩小，以及封面、背景和歌词的过渡，减少卡顿与闪动。
- **悬浮窗换句更连贯**：下一句从原位平滑上移，上一句向上模糊淡出，避免起步跳动和突然收尾；保留逐字进度、缩放与辉光。
- **减少不必要的资源占用**：减少重复取色、字体测量、文件读取与后台绘制，及时释放不再使用的内容，保留现有动效。

## 问题修复

- 手动应用歌词后，不再因旧的停用标记立即消失；专辑被停用时，仅恢复手动选择的这首歌。导入和资料库选用也适用。
- 切歌后旧搜索结果不能误用到新歌；改善部分 QQ 音乐歌词的读取与搜索结果。
- 悬浮窗启动后即可显示；修复切歌、换歌词后高度未及时更新、文字被截断，以及主窗口最小化时短暂卡顿的问题。
- 修复菜单栏歌词不显示，以及自定义字体导致字号、对齐或行距异常的问题。
- 修复切换简繁体后逐字效果失效；自定义颜色保留 EDR 辉光，改善窗口初次显示时的屏幕能力识别。
- 改善封面显示，以及缓存文件变化、异常设置值和窗口关闭引起的问题。

## 下载与安装

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.34.zip`，解压后将 `LyricsX Next.app` 放入“应用程序”。升级前先退出旧版，已有设置与歌词会保留；此前已安装 2.0.34 的用户也请替换为本次的 **252** 构建。

此安装包尚未经过 Apple 公证。如首次打开被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
