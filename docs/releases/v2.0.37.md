# LyricsX Next 2.0.37

本次更新相对 **2.0.36（271）**，安装包为 **2.0.37（272）**。

- **修复玻璃悬浮窗 HDR 偏暗**：解决长音高亮明显弱于主窗口、亮度调高后变化不明显的问题，默认配色、逐字独立配色和跟随封面颜色均适用。
- **光晕更集中**：适度收紧悬浮窗长音的外围光晕，保留逐字放大、渐进发光和高亮强度。
- **保留使用习惯**：玻璃材质、已有设置和歌词缓存保持不变；升级后首次打开会显示本次更新介绍，也可在“设置 → 关于”重新查看。

HDR 实际亮度由屏幕能力和系统可用亮度决定。

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.37.zip`，退出旧应用后，将解压得到的 `LyricsX Next.app` 替换到“应用程序”。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开如被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
