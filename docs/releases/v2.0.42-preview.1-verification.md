# 2.0.42-preview.1 发布验证

日期：2026-10-21（Australia/Melbourne）。预览版 2.0.42-preview.1，构建 277，系统数字版本 2.0.42，最低 macOS 26.0。

## 范围与问题证据

- 基于稳定版 2.0.41 的提交 `5ab145d355c1ec9847f6c60f1d241d9028e8f6c4`，只包含 #10 启动兼容性修复、打包检查和预览版介绍。不包含 #9 通用歌词偏移，也没有改动 Flexbar 功能。
- 已在原 2.0.41 公开二进制中复核 `_$s2os6LoggerV8disabledACvgZ` 导入。报告者在 macOS 26.0（25A354）上发现系统没有该符号，dyld 在启动阶段终止应用。
- 移除 LyricsKit 中的 `@Loggable` / `#log` 宏和 FrameworkToolbox 依赖；两个实际日志调用改用系统 `OSLog` / `os_log`，错误内容保留 private 标记。锁文件同时移除不再需要的 swift-syntax，没有升级其余依赖。
- 新公开包的主程序和动态库均不再导入 `Logger.disabled`。这只是已知缺失符号的检查，不代表所有 macOS 26.0 运行时兼容性已得到证明。

## 测试与实际界面

- `LYRICSX_PREVIEW_QA=1 swift test --no-parallel` 通过。运行器摘要：Services 154、Core 44、App 333 项；日志中有 40 个按条件跳过的可选测试，不将这些项目计为实机通过。
- 更新介绍与升级专项 26 项通过。覆盖从 2.0.41 升级只展示一次、保留设置、首次安装教程、跨版本介绍，以及以后同数字版本的稳定版使用新介绍 revision 时可以再次展示。
- 启用原生介绍窗口测试，在 800 × 600 内容尺寸下检查浅色和深色排版；关闭后再次自动检查不会弹出。
- `swift test --package-path Vendor/LyricsKit --no-parallel`：80 项、14 个测试组通过。
- Flexbar `npm test`：29 项通过，`npm run validate` 通过。本次不提供新的插件资产，也未验证实体设备。
- 兼容性打包检查的 6 项正反例通过，包括正常程序、带缺失符号的动态库、嵌套动态库、非二进制文件及缺失路径。原 2.0.41 公开包也会被此检查拒绝。
- 在 macOS 27.0.1（26A434）实际启动最终公开构建，主窗口正常显示已有歌曲与本地歌词；设置的关于页显示 `2.0.42-preview.1（277）`，可打开本次更新、读取修复说明并关闭。没有替换 `/Applications` 中已有的开发证书签名版本。
- `git diff --check` 和发布脚本语法检查通过。
