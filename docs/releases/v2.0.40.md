# LyricsX Next 2.0.40（275）

2026-10-01。本机更新；尚未发布到 GitHub Releases。相对上一公开版本 2.0.39，仅新增歌词位置百分比和悬浮窗文字间距。

## 功能与位置

- **主窗口歌词位置**：设置 → 歌词 → 文字 → 主窗口当前歌词位置 → 自定义。滑块或数值输入 5%–95%，越小越靠上。居中和上方预设保留，自定义值单独保存；首尾歌词、长句、翻译和窗口缩放均按有效位置对齐，边缘淡出随位置调整。
- **悬浮窗文字间距**：设置 → 歌词 → 悬浮窗文字间距。原文换行行距 0–24 pt、翻译换行行距 0–18 pt，只在两行文字之间增加间距。下一句预览使用相同原文布局后缩放。
- **段间距**：同一设置卡片关闭「段间距跟随字号」，可设置原文与辅助行 0–40 pt、翻译与下一句 0–32 pt。后者仅同时显示翻译与下一句时生效。默认仍按字号计算原有间距，一键恢复只修改间距。
- **更新介绍**：设置 → 关于 → 本次更新。两个页面提供正式设置组件；文字间距使用独立双行原文、译文和下一句演示，不控制用户正在播放的音乐，不启动音频采集。

## 排版与兼容

默认保持 2.0.39 的悬浮窗排版。自动高度、固定高度预留、测量缓存、原文/翻译绘制和离场快照均包含间距；短段间距的透明度过渡保留缓冲，静止辅助歌词不会消失。

应用标识、歌词缓存和已有设置保留。从 2.0.39 升级只自动显示本版两页一次；跨版本升级仍包含中间更新记录。
