# LyricsX Next 2.0.36

本次更新相对上一公开版本 **2.0.35（269）**，安装包为 **2.0.36（270）**。

- **Liquid Glass 歌词颜色可选自动优化**：默认调整显示颜色，让歌词在玻璃背景上更容易看清。
- **手动选色直接生效**：在玻璃悬浮窗样式下修改当前歌词、翻译与下一句，或逐字歌词的颜色时，自动优化会关闭。开关变灰后仍可点击；重新开启即可恢复优化显示。
- **保留已选颜色**：切换优化不会覆盖颜色设置，主窗口和磨砂阅读保持原有配色。启用“跟随封面主题色”时，仍优先使用封面配色。
- **设置说明与更新介绍**：在悬浮窗开关和自定义颜色处说明两种显示方式；从 2.0.35 升级后首次打开会显示这项更新，新安装仍显示完整教程。

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.36.zip`，退出旧应用后，将解压得到的 `LyricsX Next.app` 替换到“应用程序”。已有设置及歌词缓存会保留。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开如被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
