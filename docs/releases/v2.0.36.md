# LyricsX Next 2.0.36

本次更新相对上一公开版本 **2.0.35（269）**，安装包为 **2.0.36（271）**。

- **玻璃歌词配色自动适配**：使用默认配色时自动优化可读性；使用自定义颜色、逐字独立配色或跟随封面时，直接使用当前配色，不再额外改色。
- **无需手动开关**：移除独立的颜色优化开关。恢复默认配色后自动恢复优化，设置中会显示当前配色状态，并提供说明。
- **保留原有设置**：已选颜色继续保存，主窗口和磨砂阅读沿用原有配色方式。旧版颜色优化开关的值不再影响显示。
- **更新介绍同步调整**：首次升级显示本次更新；已看过此前 2.0.36 介绍的用户也会看到修正后的说明，之后不再重复。

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.36.zip`，退出旧应用后，将解压得到的 `LyricsX Next.app` 替换到“应用程序”。已有设置及歌词缓存会保留。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开如被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
