# LyricsX Next 2.0.43（279）

## MacBook Pro Touch Bar 歌词

在「设置 → 开发者选项 → MacBook Pro Touch Bar」开启「在 Touch Bar 上显示歌词」，即可在配备内置触控条的 MacBook Pro 上显示当前歌词、封面、播放/暂停和上一首/下一首。无需安装 FlexDesigner 插件，默认关闭。

带逐字时间的歌词会随演唱高亮，长句自动滚动；普通行同步歌词可以滚动阅读，不会伪造逐字高亮。只有部分文字带时间的长句，也会继续显示未标记的尾句。歌词沿用播放器当前进度、单曲与通用偏移以及简繁转换，暂停、跳转和切歌时同步更新；没有同步歌词时显示歌曲信息。

同一卡片的「后台入口（实验性）」需要单独开启。切到其他应用后，可从 Touch Bar 控制条中的歌词图标展开。后台功能依赖系统兼容性，不支持时保留应用前台的歌词显示；关闭功能、退出或睡眠会撤销应用自己的后台入口。隐藏或暂停时停止逐字刷新。

## 屏幕预览与更新介绍

「设置 → 开发者选项 → MacBook Pro Touch Bar → 打开预览」使用相同的原生控件显示当前歌曲，便于在普通屏幕检查歌词和播放控制。屏幕预览不是实体 Touch Bar 实拍，也不能验证硬件触控和显示效果。

升级后自动展示一次两页更新介绍，提供实际开关和「打开预览」按钮，不会自动启用 Touch Bar 或后台功能。以后可在「设置 → 关于 → 本次更新」重看。从更早版本升级会一并显示中间版本的介绍；原有歌词缓存、来源设置、偏移和外观设置继续保留。

## 通用包与使用范围

下载 [LyricsX-Next-2.0.43.zip](https://github.com/wzk112/LyricsX-Next/releases/download/v2.0.43/LyricsX-Next-2.0.43.zip)。此包同时包含 Apple 芯片（arm64）和 Intel（x86_64）代码，最低系统仍为 macOS 26；无法运行该系统的老款 Touch Bar Mac 不在本版范围内。2.0.42 的通用歌词偏移、macOS 26.0 启动修复和打包兼容性检查继续保留。

公开包采用 ad-hoc 签名，未经过 Apple 公证。退出旧应用并备份后，将解压的 `LyricsX Next.app` 放入 `/Applications`。首次打开方法见 [安装说明](https://github.com/wzk112/LyricsX-Next#安装)；公开包更新后，macOS 可能要求重新确认原有系统音频录制权限。

本次通过双架构构建、原生控件和 Rosetta 软件测试；实体 Intel / Apple Silicon Touch Bar 的显示、触控、跨应用展开和睡眠恢复仍待实机验证。没有重新认证真实音频权限流程、物理显示帧率或实体 Flexbar 输出。完整验证结果见 [验证记录](https://github.com/wzk112/LyricsX-Next/blob/v2.0.43/docs/releases/v2.0.43-verification.md)。
