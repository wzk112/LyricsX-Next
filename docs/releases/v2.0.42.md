# LyricsX Next 2.0.42（278）

## 通用歌词偏移

在「设置 → 歌词 → 同步 → 通用歌词偏移」输入秒数，或每次调整 0.1 秒。范围为 −300 到 +300 秒，可精确到 0.001 秒，默认 0。正值让歌词提前，负值让歌词延后。

最终偏移 = 通用偏移 + 单曲偏移。例如通用 +0.3 秒、单曲 −0.1 秒，最终提前 0.2 秒。单曲仍在主窗口底部、悬浮窗「歌词同步」或菜单栏中微调。两种偏移分别重置，互不清除。

通用值只保存到本机设置，切歌、切换歌词版本和重启后保留，不改歌词文件或播放器进度。主窗口、悬浮窗、菜单栏、逐字高亮、搜索预览及 Flexbar 共用换算；点击歌词跳转会反向换算到播放器位置。纯文本歌词不会因此产生时间轴。没有增加轮询、网络请求或播放帧率。

## macOS 26.0 启动修复

修复日志依赖引用系统缺失符号 `os.Logger.disabled` 导致双击应用没有反应的问题。移除相关日志宏和 FrameworkToolbox 依赖，两个日志调用改用系统 `OSLog / os_log`，保留私密日志标记。歌词解析和来源继续基于 [LyricsKit](https://github.com/MxIris-LyricsX-Project/LyricsKit)。打包时额外扫描主程序与随包动态库，防止已知符号回归。

[#10 报告者已确认启动修复预览版可以打开](https://github.com/wzk112/LyricsX-Next/issues/10#issuecomment-6295539654)。当前开发机为 macOS 27.0.1；这是用户在原报告环境中的启动复测，不代表在 macOS 26.0 上完成所有功能检查。最低系统仍为 macOS 26.0。

## 更新与下载

下载 [LyricsX-Next-2.0.42.zip](https://github.com/wzk112/LyricsX-Next/releases/download/v2.0.42/LyricsX-Next-2.0.42.zip)。需要 Apple 芯片 Mac 和 macOS 26 或以上。

退出旧版，备份原来的 `.app`，解压后将 `LyricsX Next.app` 放入 `/Applications`。已有歌词缓存、来源配置、单曲偏移及其他设置继续保留。从 2.0.41 或预览版升级后，正式版介绍只自动显示一次；「设置 → 关于 → 本次更新」可重看，并直接调整通用偏移。

公开包继续采用 ad-hoc 签名，未经过 Apple 公证。开发者验证提示请参照 [安装说明](https://github.com/wzk112/LyricsX-Next#安装)；更新后系统可能要求重新确认原有音频录制权限。

完整回归、实际应用检查、签名与 GitHub 下载包核验结果见 [验证记录](https://github.com/wzk112/LyricsX-Next/blob/v2.0.42/docs/releases/v2.0.42-verification.md)。真实音频权限、实体 Flexbar 和显示器物理帧率未由本次回归认证。
