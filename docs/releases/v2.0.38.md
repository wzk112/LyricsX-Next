# LyricsX Next 2.0.38

安装包版本为 **2.0.38（273）**，相对上一公开版本 **2.0.37（272）**。

## 本次变化

- **可选实时波形**：在“设置 → 悬浮窗”开启底部音频波形，选择白色或封面彩色。默认关闭；首次启用时 macOS 可能请求系统音频录制权限。应用只尝试当前识别播放器的音频；暂停、隐藏、睡眠、停止或开启减少动态效果时停止采集。权限未获准或没有可用音频时会停止绘制并显示状态，可在设置中手动重试。不同播放器、输出设备和系统权限状态的效果可能不同。
- **悬浮窗排版和过渡**：关闭波形时歌词可见行块、纯音乐歌卡在玻璃窗内居中；开启波形时歌卡与波形的上下空间更协调。歌名长短、译文、下一句变化时重新测量内容。窗口高度按内容使用可连续重定向的弹簧运动，顶部歌曲信息固定，旧歌词退场更轻；隐藏和恢复使用整窗淡入淡出。降低动态效果会结束相应动画。
- **主窗口与阅读**：调整歌词跟随和搜索预览的滚动时机，跳播或切换文档时避免旧动画继续；逐字与长音效果保留。动效同时遵循系统和应用的减少动态效果设置。
- **按需更新**：菜单栏歌词按下一句边界安排更新；Flexbar 连接在歌曲、歌词、进度纠偏或必要心跳等变化时构建快照，减少没有变化时的重复工作。刷新率选项的实际回调仍由 macOS 调度。
- **Flexbar 开发者选项**：可在“开发者选项”开启连接。使用时还需另行安装并配置 FlexDesigner 歌词插件；插件响应或测试数据不能代表设备的物理显示延迟。
- **歌曲身份与封面**：封面在后台读取，不拖住播放控制；切歌后才完成的旧封面不会显示到新歌。播放器稍后补齐歌手信息时，会用完整信息重新搜索歌词。
- **应用内引导**：四页更新介绍分别展示波形、悬浮窗排版、主窗口和 Flexbar 对应的效果；新手教程加入波形与可选 Flexbar 页面，说明采集权限、120 Hz 帧率选项和减少动态效果。Flexbar 图片来自插件离线渲染器，并非设备实拍。

已有歌词缓存、偏移、字体、颜色和悬浮窗设置会继续使用。升级不会自动开启波形，也不会自动触发音频采集权限提示。本次更新介绍在升级后首次显示一次，可从“设置 → 关于”重新查看。

## 安装与验证边界

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.38.zip`，退出旧应用，再将解压得到的 `LyricsX Next.app` 替换到“应用程序”。本项目公开包使用 ad-hoc 签名，未提供 Developer ID 公证票据；首次打开如被 macOS 拦截，请按 [安装说明](../../README.md#安装) 操作。

可选的 `LyricsX-Next-Flexbar-0.2.1.flexplugin` 是 macOS arm64 的 FlexDesigner 插件开发预览。安装应用后，在 FlexDesigner 插件页面导入它，再到本应用“开发者选项”开启 Flexbar 连接。插件需要 FlexDesigner 2.2.3 或更高版本；设备上的显示延迟和帧率尚未得到物理测量。

发布校验：完整串行 Swift 测试 **246 项通过**；Flexbar Node 测试 **29 项通过**，官方 CLI 与项目校验脚本均通过；18 组原生歌卡截图覆盖三种宽度、标题和深浅外观，与可见波形的上下间距误差为 0–2.5 pt。干净构建的 arm64 Release 应用已通过严格代码签名校验，在本机安装后成功启动，保留现有设置，并显示新版设置和四页应用内更新介绍。安装包内 Flexbar 效果图与插件渲染器输出的 SHA-256 相同。

这些验证不等同于每一种播放器及系统音频权限状态的采集结果，也不代表已测得 Flexbar 设备物理显示延迟或长时间整机功耗。可见曲线会随声音上下变化，留白不会每帧保持固定数值。
