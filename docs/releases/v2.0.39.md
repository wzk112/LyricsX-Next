# LyricsX Next 2.0.39

安装包版本为 **2.0.39（274）**，相对上一公开版本 **2.0.38（273）**。

### 功能与入口

- 主窗口歌词位置：在「设置 → 歌词 → 主窗口当前歌词位置」选择居中或上方；首尾歌词、长句和翻译均可到达所选位置，窗口尺寸或排版变化后重新定位。
- 全局快捷键：在「设置 → 通用 → 快捷键」录制、清除或恢复默认，保存后立即生效；重复绑定、无效组合与系统注册失败会显示原因。
- 封面多色配色：在「设置 → 歌词 → 跟随封面主题色」开启；波形白色／彩色在「设置 → 悬浮窗」选择。
- 更新介绍：在「设置 → 关于 → 本次更新」查看。重要设置可在介绍页直接调整；演示使用正式应用组件在 macOS 中渲染，不控制正在播放的音乐。

### 修复与优化

- 修复从暂停恢复播放后，后续轮询仍等待五秒而导致应用进度与两个歌词窗口短暂停住的问题；收到播放状态后及时恢复一秒轮询。首次读取歌词与文件信息后再读取最新播放状态和进度，避免发布过时的暂停状态。
- 修复鼠标经过隐藏歌词后，暂停播放时右上角控制条仍然残留的问题。开启「暂停时隐藏」后控制条一起隐藏；复播、移出、锁定和点击穿透切换会重新按当前状态显示。
- 优化关闭主窗口时悬浮窗的连续更新，关闭后停止主窗口绘制，重开时复用已有界面并对齐当前歌词；快捷键、Dock、菜单栏和搜索入口均可重开主窗口。实际退出应用仍释放资源。
- 主窗口切歌时短暂保留完整歌词，快速加载的歌词直接交接，减少标题闪动；新歌词以 0.52 秒的模糊、淡入和轻微位移过渡，模糊在前半段消退。同一首歌的歌词版本升级不重复播放过渡，减少动态效果时直接切换。
- 修复第一句时间轴开始前切换主歌词位置没有正确对齐的问题，等待中的第一句也会按居中或上方定位，且不会提前高亮。
- 调整窗口尺寸时复用既有模糊背景，拖动结束后更新尺寸；同一封面的尺寸刷新不再重播淡入淡出，隐藏主窗口时取消背景渲染。
- 为手动或自动返回当前歌词加入短滚动过渡，重新打开窗口或调整排版仍直接对齐；减少动态效果时立即返回。
- 悬浮窗首次显示和主窗口显隐会及时调整歌词计时器，原生窗口显隐直接恢复本窗口的显示时钟，避免等待播放器下一次采样或错过显隐通知后停帧。
- 统一主窗口与悬浮窗的封面加载交接。切歌和元数据晚到共用有限保留期限，已知封面尚在加载时不显示音符占位，旧异步结果不能覆盖新歌。
- 音频频谱复用未变化的曲线路径，减少静音或相同数据帧的图层提交；颜色、尺寸和样式变化仍会刷新。
- 修复悬浮窗歌卡切歌时短暂闪过等待布局、窗口收缩后再次展开的问题；缓存歌词结果就绪时直接交接到新内容。
- 为悬浮窗歌卡的标题和封面补上交叉淡化，短暂缺失的封面不再立即闪出音符占位；连续切歌、隐藏和减少动态效果会及时取消过时的过渡。
- 封面取色保留多种有辨识度的代表色，辅助歌词使用独立颜色，彩色波形显示真正的多色渐变；改善小面积点缀、半透明封面和暗色波形的表现，并保留灰阶封面的中性色回退。


## 安装与兼容

适用于 Apple 芯片 Mac、macOS 26 或更高版本。下载 `LyricsX-Next-2.0.39.zip`，退出旧应用，再将解压得到的 `LyricsX Next.app` 替换至“应用程序”。已有设置、歌词缓存及偏移继续保留。公开安装包使用 ad-hoc 签名，未进行 Developer ID 公证；安装步骤见 [README](../../README.md#安装)。

Flexbar 插件版本仍为 0.2.1，可继续使用，无需因这次应用更新重装插件。

## 验证与限制

发布前执行完整 Swift 串行回归、原生窗口关闭与歌词时钟专项、Flexbar 测试及插件结构校验；校验 release 构建和 GitHub 下载包的版本、签名及哈希。具体验证记录见 [v2.0.39 验证说明](v2.0.39-verification.md)。

显示回调测试不等同于物理屏幕固定帧率。未重新执行音频权限首次授权或实体 Flexbar 测试；不能据此保证所有系统负载下零掉帧。
