# LyricsX Next 2.0.33

保持现有功能、动画、帧率策略和字体布局规则的性能与生命周期维护。

- 普通歌词缓存读取合并为一次文件读取与解码，保留 UTF-8、UTF-16、GB18030 兼容及搜索检查点。
- 字体行高按实际 NSFont 缓存，最多 128 项，减少重复创建 NSLayoutManager；字号与测量公式不变。
- 缓存文件删除后清除失效路径，允许重新发现替代文件。
- 预览视图重新挂载窗口时重置可见状态，销毁时解除通知监听。
- 清理停止后的唤醒通知引用，阻止迟到回调重新显示已停止的悬浮窗。

审查范围包括播放轮询与计时、逐字渲染、悬浮窗尺寸与生命周期、搜索检查点、磁盘缓存及预览可见性。未改变渲染质量或自动搜索策略。此轮未进行受控 GPU/功耗对比，不承诺固定占用下降比例。
