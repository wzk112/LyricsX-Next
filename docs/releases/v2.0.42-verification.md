# 2.0.42 发布验证

日期：2026-10-21（Australia/Melbourne）。正式版 2.0.42，构建 278，最低 macOS 26.0，arm64。

## 发布范围

- 稳定版 2.0.41 加上 #9 通用歌词偏移与 #10 启动修复。启动修复来自已发布的 `v2.0.42-preview.1`（277），正式版在该提交上继续开发。
- 通用偏移采用「本机通用值 + 歌词文件单曲值」；不更改歌词格式或 Flexbar 协议，不增加定时器或网络请求。独立保存与重置，已有歌曲偏移保留。
- #10 报告者在原报告环境中确认预览版能打开，并据此关闭 issue；这是用户启动复测，不等于开发者在 macOS 26.0 上完成所有功能测试。开发机器为 macOS 27.0.1（26A434）。

## 自动化与原生组件

- `LYRICSX_GLOBAL_OFFSET_QA=1 LYRICSX_RELEASE_QA=1 LYRICSX_SETTINGS_QA=1 swift test --no-parallel` 通过。运行器摘要：Services 154、Core 48、App 337 项；其中 39 个可选测试按条件跳过，不把跳过项记为实机验证。
- 通用偏移与升级专项通过。覆盖正负方向、行与逐字边界、点击歌词反向跳转、暂停刷新、切歌、歌词版本切换、纯文本、空文档、极端值防溢出、正在搜索时调整、分别重置、设置重载及歌词保存隔离。
- 主窗口、悬浮窗和冻结快照使用同一偏移；Flexbar 测试验证合计偏移更新而原始播放时钟不变，Swift / Node 实际 socket 互操作通过。
- 原生设置组件通过 NSTextField 输入 0.7 秒，验证写入设置与暂停会话立即更新；检查明暗排版和 308 点内容宽度的单曲同步面板。两种偏移的数值、合计与重置说明均可读，无裁切。
- 原生更新窗口中的实际偏移输入控件验证通过；800 × 600 内容尺寸的明暗界面可用。升级与介绍回归覆盖 2.0.41、预览版同数字版本升级、一次性显示、手动重看、关闭清理和设置保留。设置各页面与教程使用正式组件进行渲染检查。
- `swift test --package-path Vendor/LyricsKit --no-parallel`：80 项、14 组通过。
- Flexbar `npm test`：29 项通过；`npm run validate` 通过。本次没有改插件协议或发布新的插件资产。
- 缺失符号检查 6 项正反例通过，覆盖主程序、嵌套动态库及错误输入；新包内两份 Mach-O 检查通过。`git diff --check` 与脚本语法检查通过。

## 最终公开包实测

- 用 `scripts/build.sh release` 生成最终公开包，在真实 macOS 中启动。关于页显示 `2.0.42（278）`，没有预览版标识；从预览版介绍记录升级时自动显示两页正式版说明。
- 在介绍的实际设置控件输入 0.7 秒，再步进到 0.8 秒；主窗口显示通用与合计 +0.800 秒，歌曲单曲值仍为 0，暂停的 Apple Music《Cubism》进度仍为 66.809 秒，没有触发 seek。
- 完全退出再打开该包，通用 0.8 秒保留，正式介绍没有重复弹出；设置 → 歌词 → 同步可继续编辑。实际输入 −0.3 秒、点击重置回 0 后，输入框、步进器及重置按钮状态一致。
- 检查字体位置、悬浮窗宽度、显示开关、波形开关和播放器设置保持原值。测试偏移已恢复到原来的 0，单曲偏移没有更改；开发机器原安装包未被替换，退出候选包后恢复原应用。

## 验证限制

本次真实播放器处于暂停；已经验证设置输入、持久化和时间换算，没有把这些结果当作主观听感校准或每款播放器实测。真实音频采集与首次权限流程、实体 Flexbar 输出、物理刷新率、长期功耗及全部在线歌词服务没有在本轮重新认证。通用偏移只调整歌词显示时间，无法纠正播放器本身不准确或持续漂移的进度。
