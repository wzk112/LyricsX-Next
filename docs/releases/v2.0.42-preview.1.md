# LyricsX Next 2.0.42-preview.1（277）

这是供 [#10](https://github.com/wzk112/LyricsX-Next/issues/10) 复测的预览版，针对 macOS 26.0 上双击应用没有反应、启动即退出的问题。基于稳定版 2.0.41，仅加入这次兼容性修复与对应的更新介绍。

## 修复内容

- 移除导致旧系统启动失败的日志宏依赖，改用系统 OSLog 保留错误日志。修复自动生效，无需调整设置。
- 打包时扫描主程序与随包动态库，拦截已知有问题的 `os.Logger.disabled` 导入。
- 保留已有歌词缓存、来源配置和单曲偏移。本预览版不包含正在开发的通用歌词偏移功能。
- 从 2.0.41 升级后只自动显示本次介绍一次，也可在「设置 → 关于 → 本次更新」重看。首次安装仍显示使用指南。

## 下载与复测

下载 [LyricsX-Next-2.0.42-preview.1.zip](https://github.com/wzk112/LyricsX-Next/releases/download/v2.0.42-preview.1/LyricsX-Next-2.0.42-preview.1.zip)。需要 Apple 芯片 Mac 和 macOS 26 或以上。

退出旧应用，备份原来的 `.app`，解压后将 `LyricsX Next.app` 放入 `/Applications` 再打开。请在 #10 反馈系统版本、能否打开主窗口，以及播放歌曲后能否正常显示歌词；如果仍然启动失败，可附新的崩溃报告。

公开包继续使用 ad-hoc 签名，未经过 Apple 公证。若遇开发者验证提示，参照 [安装说明](https://github.com/wzk112/LyricsX-Next#安装)。系统可能要求重新确认原有音频录制权限，波形功能默认状态和权限范围不因这次修复扩大。

GitHub 将此版本标记为预发布，稳定版仍为 2.0.41；应用内「检查更新」继续查询稳定版。关于页面显示完整预览版名称，系统版本号为 2.0.42，构建号 277。

## 验证范围

原正式包的缺失符号已复核，新构建不再导入该符号。发布前检查完整 Swift 回归、LyricsKit 提供方测试、实际原生更新介绍和启动，以及打包符号检查的正反例。打包后从 GitHub 草稿重新下载，对比 ZIP 与可执行文件 SHA-256，并检查严格代码签名。

当前验证机器为 macOS 27.0.1，**macOS 26.0 实机启动仍待用户复测**，因此发布预览版并保留 #10。音频权限、实物 Flexbar 输出和显示器物理帧率不属于本次已验证范围。具体结果见 [验证记录](https://github.com/wzk112/LyricsX-Next/blob/v2.0.42-preview.1/docs/releases/v2.0.42-preview.1-verification.md)。
