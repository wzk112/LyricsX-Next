# 2.0.43 发布验证

日期：2026-11-02（Australia/Melbourne）。目标版本 2.0.43，构建 279，最低 macOS 26.0，Universal（arm64 / x86_64）。

本文记录正式包的构建、软件测试、真实应用操作与发布验收方式；物理 Touch Bar 的验证范围单独列于文末。

## 发布范围与基线

- 在公开版 `v2.0.42` 上增加 MacBook Pro Touch Bar 歌词、原生屏幕预览和可选实验性后台入口，以及 Intel / Apple Silicon 通用包构建。
- 保留 2.0.42 的通用歌词偏移、macOS 26.0 已知启动符号修复和打包检查。对上一版本全部 609 个仓库文件进行实际文件比对，没有缺失；差异位于本次功能、构建和版本资料，Flexbar 插件与旧资源未回退。
- Touch Bar 和后台入口均默认关闭。新介绍提供设置位置、实际开关和预览按钮；固定演示使用正式 `TouchBarContentView`，明确标注非实体触控条画面。

## 验证限制

- arm64 原生执行与 x86_64 / Rosetta 执行属于软件验证。本轮没有实体 Intel 或 Apple Silicon Touch Bar 机器的显示、触控、跨应用展开或睡眠唤醒实测。
- 屏幕预览和截图证明同一原生组件可以绘制，不能证明物理 Touch Bar 的亮度、刷新率、延迟或触控响应。后台接口存在，也不等于当前机器具有 Touch Bar 硬件。
- 实验性后台入口依赖非公开系统接口，使用运行时检查并在不可用时保留前台显示；不同 macOS 版本上的实际表现仍需对应环境确认。
- 最低系统继续为 macOS 26.0。缺失符号检查只防止已知的 `os.Logger.disabled` 启动问题，不等于本轮已在 macOS 26.0 完成整款应用验证；无法运行 macOS 26 的老款 Intel Touch Bar Mac 不在本版支持范围内。
- 本轮没有重新认证真实系统音频授权流程、全部在线歌词服务、所有播放器、实体 Flexbar 输出、物理显示帧率或长期功耗。公开 ad-hoc 包升级后，macOS 可能要求重新确认已有的系统音频录制权限。
