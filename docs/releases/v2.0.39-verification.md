日期：2026-10-01（Australia/Melbourne）。正式版本 2.0.39，构建 274；相对 2.0.38。

## 回归与原生窗口

- `swift test --no-parallel`：Services 104、Core 42、App 281，共 427 项通过。
- 原生主窗口关闭专项：1 项完整通过，隐藏耗时 2.19ms，平时最大显示回调间隔 16.67ms，关闭阶段 23.84ms；悬浮送帧和歌词时钟继续推进，重开复用同一窗口与正文。

- 首轮发布测试发现旧主窗口回调断言不再符合原生 owner；更新为真实窗口关闭／重开及弱引用释放检查。异步测试 fixture 的临时强引用由同步 autoreleasepool 范围结束后释放；专项及后续完整串行回归均通过。
- Flexbar `npm test`：29 项通过；`npm run validate`：manifest、键、UI、后端及固定运行时校验通过。
