## 验证限制

本轮实际音乐处于暂停，尚未证明安装后真实非静音音频采集、首次授权或物理设备切换恢复。波形逻辑的回归测试不能替代这些检查。该功能默认关闭，有明确状态和手动重试入口，保留说明后随此版发布；不修改系统隐私权限或索取屏幕录制权限。

新增播放器只完成标识与识别策略验证，未逐款真实播放认证，浏览器占用系统媒体状态问题仍有局限。QQMusic 2001 为间歇服务错误，一次重试不能保证消除。云端歌词需要登录与有效订阅，地区和歌曲格式会影响返回结果；实体 Flexbar、物理刷新率与长期整机功耗没有重新验证。
