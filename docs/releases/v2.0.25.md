# LyricsX Next 2.0.25

首次以 LyricsX Next 名称发布，独立维护于 https://github.com/wzk112/LyricsX-Next 。基于 LyricsX，保留原项目历史、作者署名及 MPL-2.0 协议。

- 更新应用名称、菜单、安装包及检查更新地址。
- 保留原来的应用标识、设置和歌词缓存，旧用户无需重新配置。
- 补强悬浮窗动画收尾：显示刷新中断后也会结束模糊状态。
- 歌词宿主容纳实际内容高度，并裁切窗口外的绘制，避免歌词溢出。
- 包含 2.0.24 的 Apple Music 封面恢复与新歌词尺寸刷新修复。

从旧版升级时先退出 LyricsX，将 LyricsX Next.app 放入应用程序文件夹，并移除旧的 LyricsX.app，避免同时运行。最低要求 macOS 26。签名及首次打开说明见 README。

旧版发布以原名称保留；旧的 LyricsX 仓库仍可访问。本版未承诺已经复现和消除所有偶发的原生窗口问题。
