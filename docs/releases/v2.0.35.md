# LyricsX Next 2.0.35

**更通透的玻璃材质，更稳定的切歌与播放界面。**

本次更新相对上一公开版本 **2.0.34（258）**，安装包为 **2.0.35（267）**。

## 悬浮窗与外观

- **高透 Liquid Glass**：更新原生玻璃材质，让边缘亮光与背景折射更清晰。保留“磨砂阅读”，适合需要柔化背景时使用。
- **独立的底色透明度**：Liquid Glass 可在 0–100% 调整渐变底色，完整保留原生亮边与折射；新安装默认 60%。磨砂阅读仍可分别调节透明度与磨砂强度。
- **分别选择深浅色**：主窗口和设置支持浅色、深色或跟随系统；磨砂悬浮窗可单独选择。Liquid Glass 保持统一高透外观。
- **更清楚的歌词颜色**：改善浅色背景、自定义颜色和封面自动配色下的对比度，保留已唱与未唱的区别。调整设置页比例、间距和材质预览。

## 播放与动效

- **修复切歌时控件下沉**：长短歌名切换、专辑信息补全和歌词加载时，进度条与播放按钮保持原位，封面按可用空间适配。
- **过渡更连贯**：保留封面与文字的模糊过渡，改善悬浮窗高度动画、下一句上移和逐字绘制的流畅度，减少刷新间隔抖动。
- **辉光与 EDR 恢复**：增强普通亮度下的长音辉光，改善失去焦点、隐藏后恢复、切换屏幕与材质时的高亮恢复。实际 EDR 亮度仍由屏幕与系统决定。
- **材质切换更可靠**：减少深浅色或两种材质切换后底色残留、不恢复透明的问题。保留歌词渲染，避免滑块调整时反复重建整窗。

## 更新介绍与兼容

- **实时演示的更新介绍**：使用应用实际的材质、歌词、辉光和主窗口组件，支持切换样式、透明度与演示歌曲，也可打开独立演示悬浮窗。演示不控制正在播放的音乐，不改个人设置。
- **首次升级自动弹出**：2.0.34 升级后首次打开显示本次更新，新安装显示完整教程；关闭后不重复，可在“设置 → 关于”重新观看。隐藏或关闭演示后停止不需要的刷新。
- **保留旧版配置**：字体、配色、来源、偏移和悬浮窗位置继续使用；旧透明度自动换算，两种材质分别记忆。新高透玻璃的模糊由系统管理，需要调节磨砂时请选择“磨砂阅读”。

## 下载与安装

适用于 **Apple 芯片 Mac，macOS 26 或更高版本**。下载 `LyricsX-Next-2.0.35.zip`，退出旧应用后，将解压得到的 `LyricsX Next.app` 替换到“应用程序”。无需删除设置或歌词缓存。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开如被系统拦截，请按 [安装说明](https://github.com/wzk112/LyricsX-Next#安装) 操作。
