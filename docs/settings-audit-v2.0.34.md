# 2.0.34 设置与介绍页审查

| 区域 | 检查与处理 |
| --- | --- |
| 通用 | Dock／菜单栏／合并歌词入口保留；所有布尔偏好逐项测试 true/false 持久化。登录启动增加提交互斥、系统状态刷新、待批准入口与局部错误。 |
| 播放器 | 自动、指定播放器与重新连接行为保留，沿用播放器服务回归测试；浏览器排除规则不变。 |
| 悬浮窗 | 点击穿透与锁定联动保留，鼠标经过隐藏显示生效条件；降低透明度时说明系统限制；宽度校验与多行布局回归通过。 |
| 歌词 | 简繁体与逐字映射修复，纯文本也转换；字体名称缓存、动态辅助字号、主题色开关与配色恢复；旧数值范围校验。 |
| 动效 | 系统减少动态效果提示；辉光／EDR／逐字回归，介绍页遵循应用减少动态效果；原有帧率策略不变。 |
| 搜索 | 来源启用排序、严格匹配、逐字和双语偏好保留，沿用候选评分／检查点测试；没有为了界面审查向全部歌词源发请求。 |
| 开发者选项 | 帧率、目录、导入导出、令牌、诊断、排除记录入口保留。未为验证界面改写音乐资料库、钥匙串或用户歌词文件。 |
| 关于 | 修正新仓库与许可链接；添加完整教程和本次更新重看入口。 |

## 导航布局
重新实现设置导航壳层，不再使用 NavigationSplitView 的工具栏收缩；独立开合按钮只改变本地边栏宽度，不关闭或重新创建设置窗口。边栏统一使用原生 SF Symbols、14 pt 中等字重与 26 pt 图标底板，所有分类使用一致行内边距。卡片改为系统背景与轻描边，统一说明行距。右侧阅读列按整个设置窗口宽度确定，收起／展开边栏只移动列的位置，不在动画每一帧重新换行或改变材质预览尺寸；手动调整窗口大小仍正常适配。

## 介绍页
- 历史判断在 Preferences 初始化及迁移前执行，避免新用户被默认写入误判为已有安装。
- 新用户看完整教程；已有偏好但无历史的旧用户看近期更新摘要；已记录版本的用户看版本之间的更新。
- 同版本重启或重装不再自动展示；手动重看不会改变自动展示记录。
- 关闭介绍窗口释放托管视图与计时；动态示例只在页面及窗口可见时运行，30 Hz 上限。
- 最小窗口尺寸下逐页渲染 8 个设置区域、自动配色状态、10 页教程及 6 页当前更新。

## 取色
32×32 CPU 采样，忽略低透明像素、近黑像素与灰白边框，以加权色相分组选择主体色。取色仅随封面更新；手动配色不被覆盖。主背景适度提升饱和度并烘焙低强度主题底色到已有的小尺寸背景缓存，未增加实时全窗口滤镜。

## 已知边界
清除应用偏好后无法可靠区分首次安装与主动重置，视为首次使用。简繁体映射仅针对验证过的转换并保持字素数量的文本，无法可靠映射的任意替换仍退回行级显示，避免错配时间。颜色不能保证在所有外部桌面背景上都有相同对比度；复杂背景可选磨砂阅读。没有宣称穷尽所有设备与网络故障，也未测定固定 GPU／功耗降幅。

## 后续资源审查
补充了悬浮窗／主窗口模型、计时器、搜索取消、资料库关闭、路径缓存上限、子进程输出上限与极端偏移测试。独立配置的缓存目录也改为读取同一个 UserDefaults 域。完整细节见 `../performance/resource-audit-2.0.34.md`。
